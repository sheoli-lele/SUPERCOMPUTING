## Task 2 : Download Data

Download the files from the[NCBI FTP server](http://ftp.ncbi.nlm.nih.gov), which allows anonymous access (unlike other ftp servers, which require username + password)

Go to genomes/all/GCF/000/005/845/GCF_000005845.2_ASM584v2/

Downloaded these 2: 

1) GCF_000005845.2_ASM584v2_genomic.fna.gz
2) GCF_000005845.2_ASM584v2_genomic.gff.gz

```bash
# download sequence 1 
wget https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/005/845/GCF_000005845.2_ASM584v2/GCF_000005845.2_ASM584v2_genomic.fna.gz
# now sequence 2
wget https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/005/845/GCF_000005845.2_ASM584v2/GCF_000005845.2_ASM584v2_genomic.gff.gz

# peak at both files
zcat GCF_000005845.2_ASM584v2_genomic.fna.gz | head -n 10
zcat GCF_000005845.2_ASM584v2_genomic.gff.gz | head -n 10

# now, these are in the assignment_02 directory, but we want them in data/
mv *.gz data/
cd data
ls -ahl # verify successful move
```
Now, we want these files unzipped -- we want to reverse the compression (done to make them easier to transport), so the file is more accurate. For example AAAAAAAAAA gets compressed to A10 or something similar, but we don't want this

```bash
# unzip them
gunzip *.gz # this will remove .gz extension
# files should now be .fna and .gff, verify this : 
cd data
ls -l
```

## Verify File Integrity 

Just by moving files around, we run the risk of file corruption. Use Md5sum to generate a value that can only be generated by a specific file ; if even ONE character gets changed, the has associated with the file is completely different.

```bash
# create file
nano text.sh
md5sum text.sh
# ede2872bedbfe10342bb1c416e2f049f  text.sh

# now change one character
md5sum text.sh
# fe8cf23db58abc1351a3e82069574562  text.sh 
```

## Bash Aliases

An alias is an easier way to access something than it would otherwise be (to type in path, etc). Use config (.zschrc) file to do this. This is basically an instruction manual for the software, allowing you to customize how a program behaves without having to rewrite/recompile actual code

```bash
echo $SHELL
# this is how i now it's ~/.zshrc NOT ~/.bashrc
nano ~/.zshrc  # enter config file -- just a text file
alias bora='ssh smlele@bora.sciclone.wm.edu"
# exit file
source ~/.zshrc 
```

## Reflection

What I enjoyed most about this assignment was that it forced me to investigate the innerworkings of command-line features I previously thought of as overly technical things that could be abstracted away. I realize now that this is the beauty of Unix-like operating systems : the presence of many many tools that each complete one task well (rather than having fewer and more complex tools to learn). 

One such feature is the file permissions' division into user, group, and others. It's surprising how easy it is to change file permissions or user with the command-line -- for something with potentially high security stakes, it seems a little too easy ... 

I struggled most with figuring out the specific commands it took to use command-line FTP. I even learned some commands, including these ones : 


The presence of so many tools makes it difficult to know very many of them, and the only way to learn them is to require their use in a broader project, then stumble upon them.
